# Shrujal DevOps Portfolio

A static portfolio site built with HTML, CSS, and JavaScript. GitHub Actions publishes the site to GitHub Pages; no Java runtime, build step, or server is required.

## Deploy to GitHub Pages

1. Push this repository to GitHub.
2. In the repository, open **Settings → Pages** and set **Build and deployment → Source** to **GitHub Actions**.
3. Push to the `main` branch or run **Deploy portfolio to GitHub Pages** from the Actions tab.

The site is published directly from the project folder. For a project repository, the URL is `https://<owner>.github.io/<repository>/`. GitHub shows the final URL in **Settings → Pages** after the first successful deployment.

## Preview locally

Open `index.html` in a browser, or serve this folder with any static file server.

## Personalize

Review the field-note drafts before publishing. Add your LinkedIn profile URL when available, and verify the résumé dates and certification status before deployment.
