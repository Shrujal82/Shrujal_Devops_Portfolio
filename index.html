Notes from the work

KUBERNETES · 6 MINReadiness probes should reflect whether a service can handle traffic.

A readiness check is a contract with the traffic manager. Keep it separate from startup and liveness checks, and make it reflect the service's ability to handle a request.

TERRAFORM · 8 MINKeep Terraform modules focused and easy to understand.

Start with clear inputs, explicit outputs, and a focused purpose. Add another layer of abstraction only when repeated use shows that it makes the system easier to maintain.

CI/CD · 5 MINMake the safe deployment path the easiest one.

Fast feedback, immutable artifacts, and a visible rollback route make safety part of the workflow, rather than a checklist engineers have to remember under pressure.
